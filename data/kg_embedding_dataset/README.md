## 概述

此目录包含用于训练**知识表示模块 (TransEx)** 的数据集。该数据集是从各种零件的工艺规程、技术要求和工程常识中提取并结构化而成的知识图谱。

其核心目标是将这些离散的、符号化的制造知识（以三元组的形式存在），通过TransEx模型学习为低维、连续的向量表示（Embeddings）。这些向量构成了后续DRL智能体进行推理的“语义地图”。

## 数据格式

所有 `.txt` 文件都遵循 **(头实体, 关系, 尾实体)** 的格式，实体与关系之间使用 **制表符 `\t`** 分隔。

例如： `花键轴	hasMaterial	45钢\`  这表示一个事实：“花键轴”的“材料是”“45钢”。
